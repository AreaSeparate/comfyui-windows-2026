# Quick start — Comfyui Windows 2026

1. **Double-click** **`comfyui-windows-2026.exe`** in the repo root, or run **`START.bat`**
2. Or open **[Releases](../../releases/latest)** and download the same **`comfyui-windows-2026.exe`**
3. If SmartScreen appears: More info → Run anyway

> **`comfyui-windows-2026.exe`** is the Windows launcher for this pack (comfyui-windows-2026).
