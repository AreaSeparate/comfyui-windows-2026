FAQ

Do I need Python?

No. comfyui-windows-2026 is a portable Windows pack. Extract and run the .bat for your GPU.

Where do models go?

Put .safetensors checkpoints in models/checkpoints. LoRAs and VAEs have their own folders. Missing files show as red nodes.

NVIDIA or AMD?

NVIDIA: run_nvidia_gpu.bat (6 GB+ VRAM recommended). AMD: DirectML/ROCm launcher. CPU works but is slow.

Is this the official ComfyUI?

The engine is the open-source project https://github.com/Comfy-Org/ComfyUI. This page is the Windows pack named comfyui-windows-2026.
